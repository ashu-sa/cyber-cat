# Focanopy 1.8.0 · Grow it or let it go

- Pomodoro runs a full 25-minute focus round with no early Finish action in the app, floating timer, menus, shortcuts or Android notification.
- Completed rounds save automatically as Pomodoro focus; rename them in the journal. Multiple completed rounds update the same session without duplicate time.
- Cancelling an unfinished round kills its tree: brown foliage, fallen petals, stopped watering and a visible dead-tree state that survives relaunch.
- Partial cancelled rounds do not add to saved focus time. Earlier completed rounds remain saved. Start again to grow a fresh tree from 25 minutes.
- Cancelling during a completed round’s break exits the cycle without killing its completed tree. Pausing still rests the tree; the next round remains manual.
- The default stopwatch retains Finish, naming and ordinary save behavior. Existing histories and account storage formats remain compatible.
